# MODULE_INDEX — routing table for scoped module doc packs

Read this before grepping. Each src module has a scoped doc pack at
`docs/modules/<module>/` (see CLAUDE.md §*Scoped module documentation*).
Route: this index → the module pack README → its `CANON_MAP.md` citations →
code/tests. A scoped question ("access control only") is answered by one pack
plus its cited canon, never by a global grep.
